# DELTA BRIEF — Design

Supersedes: `MEASURES-BRIEFS.md` → Design Brief (visual direction, tokens, theme usage) and the maturation items land here too.
Direction name: **Soft Materialism** (was "Ethereal Super Normal" — same skeleton, new material).

## Law Δ (replaces "history in ink, living edge in indigo")
1. Warm, tactile neutrals as the base — plaster, uncoated paper, frosted glass.
2. Charcoal carries data, type, and touch. All of it.
3. Color exists only as **temperatures of light** — large, translucent, atmospheric (haze, edge light, wake, reflection). Never saturated fill, never hue-as-accent.
4. Gravity eases in; hands ease out. (Unchanged.)

## Temperatures Δ — one per instrument
- Ridge → Butter (dawn on the ridge): plot mist gradient + card edge light.
- Sessions → Sage (air after rain).
- Night → Lavender sky + MistBlue valley depth (dusk). The night curve is no longer a color exception — it is charcoal like all data.
- Road → Blush (late sun): the runner's wake is a wide soft blush stroke *under* the charcoal progress — light left on the road. Goal echo rings in blush.
- Each card carries a faint wash of its temperature descending from its top edge (EdgeLight token) — four rooms lit differently.

## Materiality Δ
- Grain is now canonical, two layers: in-wash grain (clipped to each gradient's alpha, soft-light) + a whisper of page grain over the whole field. Grain is static — material, not effect — and is what keeps dark-mode gradients from banding.

## Hierarchy & finish Δ (maturation pass)
- Head: metric name leads at 62 % ink; period stays quiet.
- Numeral grammar: value + unit only ("24.6 h"); the head owns the period.
- Axis whispers optically inset to the plot's first/last data points (ridge 3.3 %, road 2.7 %).
- Foot padding-top 28→18: caption groups with its chart.
- Caption line box 1.35 — italic descenders never clip against the one-line ellipsis.
- Dark theme: warm charcoals (`#201E1C`/`#282523`, warm paper ink `#EBE7E2`); washes become faint glows via the opacity tokens.
